# KunInfiniteScroll

> Infinite scroll with threshold loading.
>
> Scroll infinito con carga por umbral.

## Uso · Usage

```vue
<script setup>
import { KunInfiniteScroll } from 'adverich-kun-ui'
</script>

<template>
  <KunInfiniteScroll />
</template>
```

> Con `app.use(KunUI)` el componente queda registrado globalmente y no hace falta importarlo. · With `app.use(KunUI)` the component is globally registered, no import needed.

## Props

| Propiedad · Prop | Tipo · Type | Defecto · Default | Descripción · Description |
|---|---|---|---|
| `items` | `unknown[]` | `() => [] as unknown[]` | Lista completa (se pagina internamente por batches). |
| `search` | `String` | `-` | Texto de búsqueda (filtra antes de paginar). |
| `searchableKeys` | `Array` | `() => []` | Claves donde buscar (vacío = todas). Soporta rutas `a.b.c`. |
| `itemsPerIntersection` | `Number` | `20` | Ítems que se agregan por intersección. |
| `enabled` | `Boolean` | `true` | Activa la carga por scroll. |
| `rootMargin` | `String` | `'0px'` | Margen del observer respecto al viewport. |
| `virtual` | `Boolean` | `false` | Renderiza con KunVirtualScroller en vez de lista plana. |
| `itemSize` | `Number` | `48` | Altura estimada por ítem en modo virtual. |
| `scrollToIndex` | `number \| null` | `null` | Desplaza hasta este índice (carga batches hasta alcanzarlo). |
